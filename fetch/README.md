# Download scripts for third-party data

We do not redistribute comparison corpora or page images. These scripts fetch them from their publishers.

| Script | Fetches | Licence of the data |
|---|---|---|
| `iafetch.sh <identifier>` | OCR text of an Internet Archive item; identifiers for every edition are in `SOURCES.csv` | Public-domain texts; Google-digitised items ask for non-commercial use |
| `fetch_ridges_zenodo.ps1` | RIDGES Herbology v9.0 and the Zenodo HTR ground-truth sets (Klosterneuburg, Inzigkofen, ENHG 1480–85) | CC BY 4.0 |
| `fetch_msi_2014.py` | Beinecke multispectral images | See the Beinecke Library's terms |

The Gaskell and Bowern (2022) corpus (modified MIT) is available from the authors' repository. Page images of MS 408 are at https://collections.library.yale.edu/catalog/2002046.
